Before publishing changes to browser JavaScript or CSS, run `node scripts/version-assets.cjs` and commit the updated HTML together with the assets. This adds content hashes to asset URLs so browsers load matching styles, translations and code instead of mixing new HTML with cached files. Android packages use the same HTML and assets.
